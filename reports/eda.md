# 데이터 EDA (1주 차)

검증기(주소·업태 → 생존 합격/주의/위험)를 만들기 전에, 원본 공공데이터가
행정동에 붙는지, 시점 필터가 되는지, 업종을 같은 말로 묶을 수 있는지를 확인했다.
원본(`data/raw/`)은 읽기만 했고, 중간 산출은 `data/interim/` parquet다.

인코딩은 `cp949` → `utf-8-sig` → `utf-8` 순으로 첫 줄을 읽어 골랐다.
