# 단계 간 인터페이스 정의

각 단계는 아래에 정의한 JSON 형식만 주고받는다. 앞 단계의 출력이 다음 단계의 입력이다.
분석·생성 로직(`src/`)은 이 형식만 알고, FastAPI(`api/`)와 Next.js(`web/`)는 이 형식을 그대로 전달한다.

## 검증기 (한 달 상품, 3주 차)

주소·업태 → 시군구×업종 3년 생존과 합격/주의/위험. 화면은 이 JSON만 받는다.

`POST /verify`

```json
{
  "sido": "서울특별시",
  "sgg": "종로구",
  "business_type": "커피숍",
  "category": "카페",
  "level": "시군구",
  "n": 883,
  "surv_1y": 0.86,
  "surv_3y": 0.703,
  "nation_3y": 0.646,
  "diff_3y": 0.057,
  "grade": "합격",
  "reason": "서울특별시 종로구 카페는 3년 생존 70.3%로 전국(64.6%)보다 높다. 시군구 표본 883곳."
}
```
